# Abdou Digital Store DZ — متجر الاشتراكات الرقمية في الجزائر 🇩🇿

مشروع متجر إلكتروني متكامل مبني من الصفر خصيصاً لبيع **الاشتراكات والخدمات الرقمية في الجزائر** (Netflix 4K, Google Gemini Pro, Canva Pro, ChatGPT Plus, Spotify) بالدينار الجزائري عبر **البطاقة الذهبية (EDAHABIA)** و **بطاقة CIB** باستخدام بوابة **Chargily Pay V2** وقاعدة بيانات **Supabase** واستضافة **Vercel**.

---

## ✨ مميزات هذا المشروع الجديد

1. **مصمم 100% للمنتجات الرقمية (بدون ولايات أو بلديات أو شحن):**
   * يختار المشتري **نوع الحساب** (بروفايل مشترك، حساب خاص كامل، تفعيل على الإيميل الشخصي) و**مدة الاشتراك** (شهر، 3 أشهر، سنة).
   * يدخل الزبون **اسمه، رقم الواتساب، وبريده الإلكتروني** فقط، والشحن دائماً **مجاني وفوري (0 د.ج)**.
2. **يعمل فوراً بعد الرفع على Vercel:**
   * حتى قبل ربط قاعدة البيانات، يعرض المتجر باقات جاهزة لاشتراكات Netflix و Gemini و Canva و ChatGPT و Spotify لتجربة فورية.
3. **بوابة الدفع الإلكتروني Chargily Pay V2 + خيار الطلب عبر واتساب:**
   * يدعم الدفع بالبطاقة الذهبية و CIB أو إرسال الطلب عبر واتساب (لدفع BaridiMob / CCP).
4. **نظام تسليم رقمي فوري (`/track` و `/admin`):**
   * يمكن للزبون فتح صفحة تتبع طلبه واستلام بيانات الحساب أو كود التفعيل مباشرة من الصفحة بمجرد إرساله من لوحة الإدارة `/admin`.

## 🚀 طريقة رفع المشروع في ريبو جديد وتشغيله على Vercel (في 3 دقائق)

### 1. رفع الملفات إلى ريبو جديد في GitHub
1. فك ضغط ملف `abdou-digital-store-dz.zip` على جهازك.
2. أنشئ مستودعاً جديداً (New Repository) في حسابك على GitHub.
3. ارفع جميع محتويات المجلد (`package.json`, `vite.config.ts`, `index.html`, مجلد `src`, مجلد `supabase`, إلخ) إلى المستودع واضغط **Commit changes**.

### 2. ربط المستودع بـ Vercel
1. ادخل إلى لوحة تحكم Vercel واضغط **Add New Project** واختر المستودع الجديد.
2. في قسم **Environment Variables** في Vercel، أضف المتغيرات التالية (من مشروعك في Supabase):
   * `VITE_SUPABASE_URL` = رابط مشروعك في Supabase
   * `VITE_SUPABASE_ANON_KEY` = مفتاح `anon public` من Supabase
   * `VITE_STORE_WHATSAPP` = رقم الواتساب الخاص بك (مثال: `213699501583`)
3. اضغط **Deploy**!

### 3. تفعيل الجداول في Supabase
1. افتح **SQL Editor** في لوحة تحكم Supabase.
2. انسخ محتوى الملف `supabase/schema.sql` الموجود داخل المشروع والصقه في SQL Editor واضغط **Run**.
